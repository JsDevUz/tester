# Payments Page Backend Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace `PaymentsPage.tsx`'s mock `PAYMENT_ROWS` array with real backend data spanning all of a teacher's courses/groups, add `paymentMethod`/`note` fields to `monthly_payments`, and rework the "add payment" modal so it selects an existing cron-generated `pending`/`partial` row rather than fabricating a brand-new payment record.

**Architecture:** Two new nullable columns on `monthly_payments` (`payment_method`, `note`), a new `GET /payments` endpoint that joins across the teacher's entire course→group→member→payment hierarchy and flattens it with display context (student name, course title, group name, plan name), and a rewritten `PaymentsPage.tsx` that fetches this list, computes its filter option sets dynamically, and repurposes its modal into a "record a payment against an existing pending/partial row" flow.

**Tech Stack:** NestJS 11, Drizzle ORM, PostgreSQL, React 19, TypeScript.

## Global Constraints

- No new `monthly_payments` row is ever created by this plan — rows are exclusively created by the existing daily cron (`PaymentsCronService`, built in a prior phase). This plan only reads and records payments against existing rows.
- `paymentMethod`/`note` are both nullable and optional everywhere — `recordPayment`'s existing caller (`CourseGroupsPage.tsx`, from a prior phase) calls it with only `(paymentId, amount, discount)` and must continue to work unchanged.
- `GET /payments` and the modified `recordPayment` both require `@UseGuards(JwtAuthGuard, RolesGuard)` + `@Roles('teacher', 'super')`, matching the existing `PaymentsController`'s class-level guards.
- Ownership: `GET /payments` is scoped to the calling admin's own courses only (via `courses.adminId`), consistent with the existing `assertGroupOwnership` pattern.
- No optimistic updates — API calls awaited before local state updates.
- Manual browser QA is left to the human — automated verification is limited to `npm run build`/`npm test`.
- Backend build/test (currently 96 passing tests) must stay green; frontend build must pass.

```typescript
  async findAllForAdmin(adminId: string) {
    const adminCourses = await db.query.courses.findMany({ where: eq(courses.adminId, adminId) });
    const courseIds = adminCourses.map((c) => c.id);
    if (courseIds.length === 0) return [];

    const courseGroups = await db.query.groups.findMany({
      where: (table, { inArray }) => inArray(table.courseId, courseIds),
    });
    const groupIds = courseGroups.map((g) => g.id);
    if (groupIds.length === 0) return [];

    const members = await db.query.groupMembers.findMany({
      where: (table, { inArray }) => inArray(table.groupId, groupIds),
      with: { student: true, selectedPlan: true },
    });
    const memberIds = members.map((m) => m.id);
    if (memberIds.length === 0) return [];

    const payments = await db.query.monthlyPayments.findMany({
      where: (table, { inArray }) => inArray(table.groupMemberId, memberIds),
      orderBy: [desc(monthlyPayments.periodMonth)],
    });

    const groupById = new Map(courseGroups.map((g) => [g.id, g]));
    const courseById = new Map(adminCourses.map((c) => [c.id, c]));
    const memberById = new Map(members.map((m) => [m.id, m]));

    return payments.map((p) => {
      const member = memberById.get(p.groupMemberId)!;
      const group = groupById.get(member.groupId)!;
      const course = courseById.get(group.courseId)!;
      return {
        id: p.id,
        groupMemberId: p.groupMemberId,
        periodMonth: p.periodMonth,
        expectedAmount: p.expectedAmount,
        discountAmount: p.discountAmount,
        paidAmount: p.paidAmount,
        status: p.status,
        paymentMethod: p.paymentMethod,
        note: p.note,
        receiptUrl: p.receiptUrl,
        updatedAt: p.updatedAt,
        studentName: member.student.name,
        studentPhone: member.student.phone,
        courseTitle: course.title,
        groupName: group.name,
        planName: member.selectedPlan?.name ?? null,
      };
    });
  }
```

      </div>
    );
  }

  return (
    <div
      className="fixed inset-0 z-50 flex items-end justify-center bg-black/30 sm:items-center"
      onClick={(event) => {
        if (event.target === event.currentTarget) onClose();
      }}
    >
      <div className="w-full max-h-[92dvh] overflow-y-auto rounded-t-3xl bg-white sm:max-w-lg sm:rounded-3xl">

                      type="button"
                      onClick={() => setSelectedId(row.id)}

                          {row.courseTitle} • {formatMonthLabel(row.periodMonth)}
                        </p>

                      {selected && <Check size={16} className="text-indigo-500 shrink-0" />}
                    </button>
                  );
                })}
              </div>
            </div>
          </Field>

          {selectedRow && (

              <p className="font-semibold text-gray-800">{selectedRow.studentName}</p>

              </p>
            </div>
          )}

            <input
              value={amount}
              onChange={(event) => setAmount(event.target.value.replace(/[^\d\s]/g, ""))}
              placeholder="300000"
              className="w-full rounded-2xl bg-gray-50 px-4 py-3 text-sm outline-none"
            />
          </Field>
          <Field label="To'lov turi">
            <SelectField<PaymentMethod>
              value={method}
              onChange={setMethod}
              options={METHOD_OPTIONS}
              getLabel={(value) => METHOD_LABEL[value]}
            />
          </Field>
          <Field label="Izoh" className="sm:col-span-2">
            <textarea
              rows={3}
              value={note}
              onChange={(event) => setNote(event.target.value)}
              placeholder="Ixtiyoriy izoh"
              className="w-full resize-none rounded-2xl bg-gray-50 px-4 py-3 text-sm outline-none"
            />
          </Field>
          <Field label="Chek rasmi (ixtiyoriy)" className="sm:col-span-2">
            <label className="flex cursor-pointer items-center gap-2 rounded-2xl bg-gray-50 px-4 py-3 text-sm text-gray-500 hover:bg-gray-100">
              <input type="file" accept="image/*" className="hidden" onChange={handlePickReceipt} />
              <Paperclip size={16} className="shrink-0 text-gray-400" />
              <span className="min-w-0 flex-1 truncate">
                {receiptFile ? receiptFile.name : "Chek rasmini tanlang"}
              </span>
              {receiptFile && (
                <button
                  type="button"
                  onClick={(event) => {
                    event.preventDefault();
                    setReceiptFile(null);
                  }}
                  className="shrink-0 rounded-lg p-1 text-gray-400 hover:bg-gray-200 hover:text-gray-600"
                >
                  <X size={14} />
                </button>
              )}
            </label>
          </Field>
          <button
            type="button"
            onClick={handleSave}
            disabled={!canSave || saving}
            className="sm:col-span-2 rounded-2xl bg-indigo-500 py-3 text-sm font-semibold text-white transition-colors hover:bg-indigo-600 disabled:cursor-not-allowed disabled:opacity-40"
          >
            {uploadingReceipt ? "Chek yuklanmoqda..." : saving ? "Saqlanmoqda..." : "Saqlash"}
          </button>
        </div>
      </div>
    </div>
  );
}
